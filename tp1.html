Exercice 1 — Ma première page Web

  1. Objectif du TP

    • Découvrir l'environnement de développement Web.

    • Modifier et visualiser une page Web.

  2. Création du fichier

    Nom du fichier :tp1.html

  3. Contenu de la page

    La page doit contenir :

    • Un titre principal :

    Ma premiere page web

    • Le prénom de l’étudiant :

    Ichrak

    • Le domaine d’étude :

    Informatique

    • Un paragraphe de présentation :

    Je m'appelle Ichrak. Je suis étudiante en informatique et je m'intéresse au développement Web.

    Je souhaite apprendre le développement Web pour améliorer mes compétences en informatique.

    Ajouter :

    • Un deuxième titre :

    mon domaine d'etude

    Le développement Web permet de créer des sites Web modernes et interactifs.

    W3Schools

    Décrire brièvement le résultat de la page :
